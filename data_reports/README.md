# 📊 Data Reports

This folder contains analytical SQL reports created from the Gold Layer of the data warehouse.

The reports transform cleaned and modelled warehouse data into business-ready datasets for reporting, analysis, and dashboard development.

## Reports

### 👥 Customer Report
Provides customer-level analysis including:

- Customer demographics
- Customer segmentation
- Total orders
- Total sales
- Total quantity purchased
- Product diversity
- Customer lifespan
- Recency
- Average order value
- Average monthly spend

➡️ [View Customer Report](customer_report/)

---

### 📦 Product Report
Provides product-level analysis including product sales performance, customer activity, and key product KPIs.
