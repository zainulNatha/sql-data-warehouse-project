# 👥 Customer Report

## Overview

The Customer Report provides a consolidated customer-level view built from the **Gold Layer** of the data warehouse.

The report combines customer and sales transaction data to analyse customer behaviour, purchasing activity, engagement, and overall value.

The final dataset produces **one row per customer** and is stored as the following SQL view:

```sql
gold.report_customers
```

---

## 🎯 Report Objectives

The report was created to:

* Combine sales transactions with customer information.
* Calculate customer age and assign customers to age groups.
* Aggregate transactional data to the customer level.
* Calculate total orders, sales, quantity purchased, and unique products purchased.
* Identify each customer's latest order date.
* Calculate customer lifespan based on first and latest purchases.
* Measure customer recency.
* Calculate average order value.
* Calculate average monthly spend.
* Segment customers into **VIP**, **Regular**, and **New** categories.

---

## 📊 Key Customer Metrics

| Metric              | Description                                                    |
| ------------------- | -------------------------------------------------------------- |
| `total_orders`      | Number of unique orders placed by each customer                |
| `total_sales`       | Total sales generated by each customer                         |
| `total_quantity`    | Total quantity of products purchased                           |
| `total_products`    | Number of unique products purchased                            |
| `last_order_date`   | Most recent order placed by the customer                       |
| `lifespan`          | Number of months between the customer's first and latest order |
| `recency`           | Number of months since the customer's latest order             |
| `avg_order_value`   | Average sales value per order                                  |
| `avg_monthly_spend` | Average customer spend per month                               |

---

## 👤 Customer Segmentation

Customers are categorised based on their lifespan and total sales.

| Segment     | Business Rule                               |
| ----------- | ------------------------------------------- |
| **VIP**     | Lifespan ≥ 12 months and total sales > 5000 |
| **Regular** | Lifespan ≥ 12 months and total sales ≤ 5000 |
| **New**     | Lifespan < 12 months                        |

Customers are also grouped by age:

* Under 20
* 20–29
* 30–39
* 40–49
* 50 and above

## 🛠️ SQL Techniques Used

### Common Table Expressions (CTEs)

CTEs were used to separate the report into logical processing stages.

```sql
WITH base_query AS (...),
customer_aggregation AS (...)
```

The `base_query` retrieves and prepares the required customer and transaction data.

The `customer_aggregation` CTE then summarises the transactional data at customer level.

---

### LEFT JOIN

```sql
LEFT JOIN gold.dim_customers c
    ON c.customer_key = f.customer_key
```

Used to combine customer information from the customer dimension with sales transactions from the fact table.

---

### CONCAT

```sql
CONCAT(c.first_name, ' ', c.last_name)
```

Combines the customer's first and last name into a single `customer_name` field.

---

### DATEDIFF & GETDATE

```sql
DATEDIFF(year, c.birthdate, GETDATE())
```

Used to calculate customer age.

`DATEDIFF` is also used to calculate:

* Customer lifespan
* Customer recency

---

### Aggregate Functions

Several aggregate functions are used to transform transaction-level data into customer-level metrics.

```sql
COUNT(DISTINCT order_number)
SUM(sales_amount)
SUM(quantity)
COUNT(DISTINCT product_key)
MIN(order_date)
MAX(order_date)
```

These calculate customer orders, sales, quantity, product diversity, and purchase dates.

---

### GROUP BY

```sql
GROUP BY
    customer_key,
    customer_number,
    customer_name,
    age
```

Used to aggregate multiple sales transactions into a single record for each customer.

---

### CASE Statements

`CASE` expressions apply business logic to the report.

They are used for:

* Customer age groups
* Customer segmentation
* Handling zero values when calculating averages

Example:

```sql
CASE
    WHEN lifespan >= 12 AND total_sales > 5000 THEN 'VIP'
    WHEN lifespan >= 12 AND total_sales <= 5000 THEN 'Regular'
    ELSE 'New'
END
```

---

### CREATE VIEW

```sql
CREATE VIEW gold.report_customers AS
```

The completed report is saved as a reusable SQL view within the Gold Layer, making it available for reporting, analysis, and dashboard development.
